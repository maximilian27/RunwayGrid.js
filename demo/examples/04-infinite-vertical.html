4. Infinite scroll (vertical, variable row height)

Starts with a small page of rows and fetches (simulated) more from a "server" as soon as the buffered range gets close to the end of the currently loaded data - i.e. before the user actually scrolls to the bottom. New pages are appended via appendData(), so the scroll position is never reset. Row heights vary per item.
