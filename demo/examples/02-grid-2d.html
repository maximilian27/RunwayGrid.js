2. 2D grid (independent vertical + horizontal panning)

A 100,000 x 500 cell grid with both axes virtualized independently via orientation="both". Every 10th row is taller and every 5th column is wider, to demonstrate that row heights and column widths are tracked per-axis and combined.

examples/02-grid-2d.html

API used in this example

APIUsage
orientationSet to "both" - rows and columns are virtualized independently.
row-size / col-sizeInitial estimates (28px / 120px) before real sizes are auto-measured.
columnsSet to a 500-entry array (drives colCount), before data.
dataSet to a 100,000-entry row array (drives rowCount).
templateSignature (rowItem, rowIndex, colIndex, rowCount, colCount); varies height/width by index.
scrollToCell(rowIndex, colIndex)Used by the Top-Left/Bottom-Right buttons.
rangechangeLogs both row and column ranges for e.buffered/e.viewport.
