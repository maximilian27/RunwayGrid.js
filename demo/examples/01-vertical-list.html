1. Vertical list (single column)

A single-column, vertically virtualized list over 1,000,000 rows. The template function switches between three distinct row layouts (section header, media card, compact row) based on the row index, to show that row heights can vary arbitrarily and are auto-measured. Data-derived text is run through escapeHtml() before being interpolated into the innerHTML template string.

API used in this example

APIUsage
