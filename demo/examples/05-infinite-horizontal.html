5. Infinite scroll (horizontal, variable column width)

Same idea as the vertical infinite-scroll example, but along the column axis: appendData() grows the columns (not the rows) when orientation="horizontal", since the column axis is what carries the items for a horizontal list. Column widths vary per item and are auto-measured, same as the horizontal list example.
