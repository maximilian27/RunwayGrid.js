3. Horizontal list (single row, varying item widths)

A single-row, horizontally virtualized list of 5,000 chips with orientation="horizontal". Each cell's DOM width is left unset, so its rendered width comes purely from its content - the component measures the actual rendered width via ResizeObserver and grows/shrinks the virtual column to match.

examples/03-horizontal-list.html

API used in this example

APIUsage
orientationSet to "horizontal" - the column axis carries the items; rowCount stays 1.
col-sizeInitial width estimate (120px), only used before the real width is auto-measured.
columnsSet to a 5,000-entry array, before data, to drive colCount.
dataSet to a single-entry placeholder array ([null]) - required to trigger registry setup.
templateIgnores rowItem; renders a chip based on colIndex alone.
scrollToCell(0, colIndex)Used by the Jump/Start/End buttons (row is always 0).
rangechangeLogs e.buffered.startCol/endCol and the viewport equivalents.
