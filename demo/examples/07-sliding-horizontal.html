7. Sliding window / infinite scroll (horizontal, memory-capped)

Same idea as the vertical sliding-window example, but along the column axis: once a new page is appended via appendData(), columns beyond the cap are pruned from the left via removeDataFromHead(), which counter-scrolls the horizontal axis so nothing jumps. The columnsData array (and the WASM column vectors) never grows past the cap, keeping memory flat during infinite horizontal scrolling.

API used in this example

APIUsage
appendData(newItems)Appends each fetched page along the column axis, exactly like the horizontal infinite-scroll example.
removeDataFromHead(count)Called immediately after each append if colCount > 1000, dropping the oldest columns and counter-scrolling so nothing jumps.
colCount (readonly)Checked after each append to decide whether the 1,000-column cap was exceeded.
columnsData (readonly)Read for the fetch threshold check and indexed by colIndex inside template.
