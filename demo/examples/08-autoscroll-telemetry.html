8. Telemetry log (live stream & auto-scroll)

Demonstrates continuous live telemetry streaming with native auto-scrolling (startAutoScroll() / stopAutoScroll()). As new events are continuously appended, the scroller automatically glides to keep the latest event visible at the tail. The ticker automatically pauses when hovering over the grid to allow inspecting log lines, resumes on mouseout to catch up with the stream, and suspends whenever the user manually scrolls up.

Live Stream & Auto-Scroll Behavior:
  • Continuous ingestion: New telemetry items are appended to the list continuously via appendData() without needing full data resets.
  • Follow tail: While auto-scroll is on, incoming items automatically advance the scroller so the latest row remains visible.
  • Pause on hover: Hovering your mouse over the terminal pauses scrolling so you can inspect historical rows without the view scrolling away.
  • Restart on mouseout: Moving the mouse out resumes auto-scrolling and smoothly catches up to the stream.
  • Manual scroll override: Scrolling up via mouse wheel or dragging the scrollbar track suspends auto-scroll so you can browse freely; click the floating badge or "Follow Tail" to resume.

API used in this example

APIUsage
startAutoScroll(speed)Initiates the native requestAnimationFrame loop that smoothly glides to keep the last item in view as items are added.
stopAutoScroll()Cancels the auto-scroll ticker when the user manually scrolls or pauses follow mode. Also called on element disconnect.
appendData(newItems)Continuously appends real-time incoming events to the virtual registry without rebuilding layout state.
mouseenter / mouseleaveBuilt-in hover detection pauses auto-scrolling during inspection and resumes on mouseout.
handleWheel / handleTrackScrollSuspends auto-scrolling when manual user gestures move the viewport up to inspect past logs.
scrollToIndex(index)Snaps directly to the start (T+0) or latest tail event.
rangechangeTracks currently visible and buffered rows as new events stream into the virtual scroller.
