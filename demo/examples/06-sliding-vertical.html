6. Sliding window / infinite scroll (vertical, memory-capped)

Combines infinite loading with a hard cap: once a new page is appended via appendData(), if the loaded row count exceeds the cap, the oldest rows are pruned from the top via removeDataFromHead(). The viewport is counter-scrolled by the exact removed pixel height in the same frame, so scrolling stays perfectly smooth even though the array (and the WASM vectors backing it) never grows past the cap - memory usage stays flat forever, no matter how far down the user scrolls.

API used in this example

APIUsage
appendData(newItems)Appends each fetched page, exactly like the infinite-scroll example.
removeDataFromHead(count)Called immediately after each append if rowCount > 1000, dropping the oldest rows and counter-scrolling so nothing jumps.
rowCount (readonly)Checked after each append to decide whether the 1,000-row cap was exceeded.
rows (readonly)Read for the fetch threshold check and to display the current loaded count.
